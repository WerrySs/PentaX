# PentaX brand assets

Project-supplied rounded PentaX monogram with its separate upper-right violet
accent. PNG files are unmodified exports from the current identity pack.
Matching SVG geometry, transforms, colors and margins are unchanged; only
accessibility labels and identifiers are translated into English.

| Role | Color |
| --- | --- |
| Soft black | `#0B0D15` |
| Violet | `#8B5CF6` |
| White | `#FFFFFF` |
| Lavender | `#F5F3FB` |
| Secondary lilac | `#B79AFF` |
| Graphite | `#1A1824` |

Use `logo-dark` on dark surfaces, `logo-light` on light surfaces and `app-icon`
for the native window icon. Scale proportionally and preserve the supplied
margins and component positions. The desktop keeps its reference layout and
supports a configurable user accent.
